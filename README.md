# 🎵 Sonora

Sonora is a modern Spotify-inspired music streaming web application built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features

- 🎧 Modern Spotify-like interface
- 📱 Fully responsive design
- 🎵 Music player with playback controls
- 📀 Albums, artists & playlists
- 🔍 Search functionality
- ❤️ Like songs
- 📃 Queue management
- ⚡ Fast performance
- 🎨 Beautiful animations
- 🌙 Clean and modern UI

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React
- Zustand (State Management)
- Lucide Icons
